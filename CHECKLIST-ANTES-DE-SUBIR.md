# Checklist antes de subir para o Cloudflare Pages

- [ ] Trocar domínio provisório `https://popzun.com.br`, se for outro.
- [ ] Atualizar `sitemap.xml`.
- [ ] Atualizar `robots.txt`.
- [ ] Atualizar `ads.txt` quando tiver rede de anúncios.
- [ ] Trocar e-mail da página de contato.
- [ ] Revisar política de privacidade e termos.
- [ ] Testar com Live Server.
- [ ] Conferir se não tem imagem quebrada.
- [ ] Conferir se todos os artigos cadastrados no `posts.js` existem.
- [ ] Conferir se todos os artigos têm imagem.
- [ ] Subir para GitHub.
- [ ] Conectar no Cloudflare Pages.
