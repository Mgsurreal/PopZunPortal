# Modo produção local até segunda-feira

Como ainda não vai subir para GitHub agora, o fluxo local é este:

1. Criar ou editar artigo dentro da pasta `artigos/`.
2. Colocar imagem em `assets/img/posts/`.
3. Cadastrar o post em `assets/js/posts.js`.
4. Abrir com Live Server.
5. Testar home, categoria, artigo, busca e botão de compartilhar.
6. Quando estiver tudo certo, deixa a pasta guardada.
7. Segunda-feira, subir a pasta inteira para o GitHub.

## O que testar sempre
- Home abre sem erro.
- Menu funciona.
- Busca abre.
- Artigo abre.
- Relacionados aparecem.
- Banner inferior fecha.
- Cookie fecha.
- Imagens aparecem.
