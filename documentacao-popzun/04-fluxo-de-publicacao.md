# 04 — Fluxo de publicação

## Fluxo padrão

1. Escolher pauta.
2. Confirmar fato em fontes confiáveis.
3. Criar título forte.
4. Criar resumo.
5. Criar thumb impactante.
6. Criar artigo em HTML.
7. Abrir PopZun Studio.
8. Criar estrutura.
9. Gerar thumb/OG.
10. Colar artigo.
11. Publicar.
12. Conferir home/categoria/post.
13. Divulgar nas redes.

## Dados necessários para cada artigo

- Título
- Slug
- Categoria
- Resumo
- Autor
- Tags
- Thumb
- ALT da thumb
- Conteúdo do artigo
- SEO description
- Open Graph description

## Padrão de slug

Sempre minúsculo, sem acento, separado por hífen.

Exemplo:

```txt
bonnie-tyler-morre-aos-75-anos-e-internet-relembra-musica-que-marcou-geracoes
```

## Estrutura do artigo

Modelo simples:

```html
<article class="article-content">
  <p>Introdução curta e direta.</p>

  <h2>Subtítulo forte</h2>
  <p>Texto do bloco.</p>

  <div class="ad ad-in-article">
    <span>ANÚNCIO</span>
    <strong>Espaço reservado</strong>
  </div>

  <h2>Outro bloco</h2>
  <p>Texto.</p>
</article>
```

## Após publicar

Conferir:

- apareceu na home;
- apareceu em recentes;
- apareceu na categoria correta;
- busca encontra o título;
- card abre o artigo;
- imagem do card aparece;
- artigo tem title, description e Open Graph;
- anúncio não atrapalha leitura.

## Artigos de teste

Enquanto o site ainda não estiver no ar, pode manter posts de exemplo.

Antes de publicar oficialmente:

- criar pelo menos 10 posts reais;
- testar Studio;
- testar categorias;
- testar compartilhamento;
- deletar posts de exemplo pelo botão do Studio;
- subir versão limpa.
