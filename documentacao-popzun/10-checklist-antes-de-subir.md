# 10 — Checklist antes de subir

Antes de colocar o PopZun na internet, conferir:

## Conteúdo

- [ ] Pelo menos 10 posts reais publicados.
- [ ] Posts de exemplo deletados ou escondidos.
- [ ] Categorias funcionando.
- [ ] Busca funcionando.
- [ ] Relacionados funcionando.
- [ ] Nenhum título fake.
- [ ] Nenhuma imagem roubada.

## Studio

- [ ] Cria estrutura sem resetar.
- [ ] Gera thumb.
- [ ] Gera OG.
- [ ] Publica artigo.
- [ ] Atualiza posts.js.
- [ ] Atualiza sitemap.
- [ ] Rascunhos funcionam.
- [ ] Verificador não acusa erro grave.

## SEO/Social

- [ ] Cada artigo tem `<title>`.
- [ ] Cada artigo tem meta description.
- [ ] Cada artigo tem og:title.
- [ ] Cada artigo tem og:description correto.
- [ ] Nenhum og:description usando slug.
- [ ] Cada artigo tem og:image.
- [ ] Caminho da imagem social está correto.
- [ ] canonical correto.

## Anúncios

- [ ] Espaços de anúncio preparados.
- [ ] Sem popup.
- [ ] Sem popunder.
- [ ] Sem onclick.
- [ ] Sem redirecionamento.
- [ ] Sem anúncio adulto/nudez.
- [ ] ads.txt configurado quando houver rede real.

## Arquivos

- [ ] robots.txt existe.
- [ ] sitemap.xml existe.
- [ ] ads.txt existe.
- [ ] favicon existe.
- [ ] páginas legais existem: Sobre, Contato, Privacidade, Termos.

## Mobile

- [ ] Home legível no celular.
- [ ] Cards bons no celular.
- [ ] Artigo fácil de ler.
- [ ] Anúncios não cobrem texto.
- [ ] Banner inferior fecha fácil.

## Final

- [ ] Testar em janela anônima.
- [ ] Testar no celular.
- [ ] Testar navegação inteira.
- [ ] Subir para GitHub/Cloudflare.
- [ ] Testar link público.
- [ ] Testar compartilhamento no Facebook/WhatsApp.
