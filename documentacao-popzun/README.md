# Documentação PopZun

Esta pasta guarda a documentação interna do projeto **PopZun**.

O PopZun é um portal estático de entretenimento, criado em HTML, CSS e JavaScript, com publicação local via **PopZun Studio** e hospedagem futura em GitHub + Cloudflare Pages.

## Como usar esta documentação

Arquivos principais:

- `01-visao-geral.md` — visão do projeto, objetivo e identidade.
- `02-estrutura-do-site.md` — como o site é organizado.
- `03-popzun-studio.md` — como funciona o Studio/local publisher.
- `04-fluxo-de-publicacao.md` — passo a passo para publicar artigos.
- `05-editorial-e-conteudo.md` — linha editorial e tipos de postagem.
- `06-seo-open-graph-e-facebook.md` — SEO, Facebook, WhatsApp e imagens sociais.
- `07-thumbs-e-imagens.md` — padrão de imagens, thumbs e uso de IA.
- `08-monetizacao.md` — anúncios, afiliados e ideias de receita.
- `09-operacao-diaria.md` — rotina de produção do portal.
- `10-checklist-antes-de-subir.md` — checagem antes de publicar na internet.
- `11-area-admin-futura.md` — ideia futura de área administrativa/documentação protegida.
- `12-perfis-e-saiba-mais.md` — sistema simples de perfis e cards Saiba Mais.
- `13-categoria-culinaria.md` — categoria evergreen para receitas fáceis, rápidas e compartilháveis.
- `PROMPT-CODEX-AREA-ADM.md` — prompt para pedir ao Codex uma área interna depois.

Também existe um `index.html` simples para ler a documentação pelo navegador.

## Atenção

Se esta pasta for enviada para o site público, **não coloque senhas, tokens, chaves de API, IDs de conta de anúncio, dados pessoais ou informações sensíveis**.

Uma senha feita só em HTML/JS não é segurança real. Ela apenas evita acesso por acidente.
