# 07 — Thumbs e imagens

## Importância da thumb

A thumb é metade do clique.

No PopZun, a imagem precisa chamar atenção antes mesmo da pessoa ler o título.

Regra:

```txt
se a thumb é genérica, o clique cai.
se a thumb dá impacto, o post tem chance.
```

## Padrão visual

- alto contraste;
- rosto grande quando for famoso;
- expressão forte, mas respeitosa;
- texto curto quando fizer sentido;
- composição simples;
- leitura boa no celular;
- sem poluição visual;
- sem cara de banco de imagem genérico.

## Texto na thumb

Pode usar texto no estilo capa de YouTube quando o assunto pedir.

Bom:

```txt
BONNIE TYLER
MORREU
AOS 75
```

Evitar:

- textos longos;
- fonte pequena;
- muito elemento;
- parecer meme em assunto sensível.

## Famosos e IA

Podemos gerar imagem de famoso com IA para uso editorial, principalmente para evitar roubar fotografia de terceiros.

Cuidados:

- não criar cena falsa comprometedora;
- não humilhar;
- não usar em contexto difamatório;
- não fingir que é foto oficial;
- em morte/homenagem, manter respeito.

## Imagens Creative Commons

Podem ser usadas quando a licença permitir uso comercial.

Cuidados:

- verificar licença;
- dar crédito correto quando exigido;
- evitar capa de álbum ou material oficial duvidoso;
- não usar imagem com licença não comercial em site monetizado.

## Nomes de arquivo

Usar nomes simples:

```txt
bonnie-tyler-morre-aos-75-thumb.jpg
situacoes-irritantes-do-cotidiano.jpg
```

## ALT

O ALT ajuda acessibilidade e SEO.

Padrão para thumb:

```txt
Imagem ilustrativa sobre [título do artigo]
```

Exemplo:

```txt
Imagem editorial em homenagem a Bonnie Tyler após sua morte aos 75 anos
```

## Prompts de thumb

### Modelo famoso/notícia

```txt
Thumb de alto impacto para portal de entretenimento sobre [tema]. Mostrar [pessoa] em destaque, com estética editorial, alto contraste, fundo dramático, composição horizontal 1200x675, texto curto e muito legível: [texto]. Visual chamativo, respeitoso, moderno, sem marcas d'água e sem imitar capa oficial.
```

### Modelo curiosidade/lista

```txt
Imagem editorial divertida e chamativa sobre [tema], com elementos visuais claros, expressão de surpresa, composição horizontal 1200x675, alto contraste, estilo portal viral, sem texto pequeno, sem logos, sem marcas d'água.
```
